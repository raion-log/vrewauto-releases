👇 여기를 눌러 설치파일을 받으세요! 👇
⬇ 맥용 설치파일 다운로드 (.dmg)
파일 이름: VrewAuto_2.0.8_universal.dmg
💡 다운로드 경고가 뜨면?
맥에서 크롬으로 받을 때 "무시하고 다운로드" 같은 경고가 나오면, 위 윈도우 탭의 2~5단계 사진과 똑같이 따라 하시면 됩니다.
2
응용 프로그램 폴더로 옮기기
받은 .dmg 파일을 더블클릭해 창이 열리면, VrewAuto 아이콘을 옆의 "Applications(응용 프로그램)" 폴더로 끌어다 놓으세요.
3
"확인되지 않은 개발자" 경고 대처
처음 실행할 때 "열 수 없습니다" 라고 나오면, 새 프로그램이라 그런 것이니 걱정 마세요.
✅ 이렇게 하세요
① 응용 프로그램 폴더의 VrewAuto 아이콘 우클릭 (트랙패드는 두 손가락 클릭) → ② "열기" → ③ 다시 "열기". 한 번만 이렇게 하면 다음부턴 그냥 켜집니다.

⚠️ 꼭 확인하세요

  • 기존 버전을 지우지 않아도 됩니다 — 자동으로 최신 버전으로 덮어쓰기 됩니다
  • 설치 후 앱을 껐다 켜야 정상 작동합니다
  • 맥(Mac) 사용자는 위 "맥" 탭의 .dmg 파일로 설치해 주세요
❓ 자주 묻는 질문
"무시하고 다운로드"를 눌렀는데 또 경고가 떠요.
정상입니다. 위 3~5단계(⋯ → 다운로드 페이지 열기 → 유지)를 그대로 따라 하시면 파일이 저장됩니다.
백신(V3, 알약 등)이 위험하다고 막아요.
새로 배포한 프로그램이라 백신이 아직 모르는 것뿐입니다. "허용" 또는 "신뢰함"으로 풀어주세요. 바이러스가 아닙니다.
