## 판 번호와 다운로드 주소를 고치는 법

**HTML 을 고치지 않는다.** 페이지가 `update/with-capcut.json` 을 읽어 판 번호·다운로드 주소·
파일 이름을 그린다. 채널 파일만 고치고 push 하면 페이지가 따라 바뀐다.

- 설치파일 주소가 **비어 있으면 페이지가 덮어쓰지 않는다.** 판 번호도 그대로 둔다 —
  버튼이 받는 파일과 표시가 어긋나지 않게
- 채널을 못 읽어도 HTML 에 적힌 기본값으로 계속 동작한다 (2026-08-12 채널 차단 전례)
- 구글 드라이브 경고 단계는 다운로드 버튼이 드라이브를 가리킬 때만 보인다. 배포 저장소
  릴리즈 주소가 채워지면 저절로 숨고 뒤 단계 번호가 다시 매겨진다
- ★`version` 은 설치파일을 릴리즈에 올리고 안내를 보낸 **뒤에** 올린다
