개선
이미지 생성 버튼이 자동으로 최신 링크로 업데이트됩니다.
⬇️ 설치 / 업데이트 방법
1
다운로드한 설치파일을 그냥 실행하세요. (기존 버전 위에 자동으로 덮어쓰기 — 지울 필요 없어요)
2
설치가 끝나면 앱을 완전히 껐다가 다시 켜주세요.
3
2.0.0 이상 사용자는 앱을 켜면 업데이트 알림이 자동으로 떠요. ‘지금 업데이트’만 누르면 끝!
🎬 자동배치 핵심 사용법
브루(텍스트로 비디오 만들기) 기준 — 딱 이 순서대로만 하면 됩니다
1
브루에서 ‘클립 나누기’ 설정하고 저장
브루에서 영상 작업을 마친 뒤, 원하는 대로 클립(컷)을 나눠 주세요. 그 상태로 브루 프로젝트(.vrew)를 저장합니다.
👉 자동배치는 이 클립 단위로 이미지를 넣기 때문에, 클립 나누기를 먼저 끝내는 게 핵심이에요.
▲ 브루 ‘자동 클립 나누기’ — 전체 클립 · 의미 기준으로 나눈 모습
2
이미지 프롬프트 TXT 파일 준비
씬별 이미지 키워드가 담긴 텍스트 파일(.txt)을 준비하세요. 형식은 아래와 같아요.
##1 :::S::: 씬 원고 내용 :::I::: 이미지 키워드
TIP · ##번호 / :::S::: / :::I::: 기호는 그대로 있어야 해요. 씬 개수가 브루 클립과 맞으면 가장 깔끔하게 배치됩니다.
3
프로그램에 파일 3개 올리기
VrewAuto를 켜고 자동배치 화면에서 아래 3개를 올려주세요. (드래그하거나 카드를 클릭해서 선택)
📝
프롬프트2번에서 만든 .txt
📁
VREW방금 저장한 .vrew
🖼️
IMAGES이미지들이 든 폴더
▲ 프롬프트 · VREW · IMAGES 3개가 올라가면 카드에 초록 체크(✓)가 떠요
헤이젠(HeyGen)으로 만든 분은 위 3개에 SRT 자막 파일까지 = 총 4개를 올리고, ‘헤이젠 SRT 사용’을 켜주세요.
4
언어 선택 → 매칭 실행
한국어 / 일본어 / 영어 중 영상에 맞는 언어를 켜고, 보라색 [▶ 매칭 실행] 버튼을 누르세요. 잠시 기다리면 아래 로그(LOG)에 진행 상황이 뜨고 이미지가 씬별로 배치됩니다.
▲ 언어·이미지 배치 선택 후 [▶ 매칭 실행] → 로그로 진행 확인
5
결과 ‘Vrew 열기’로 확인
매칭이 끝나면 [Vrew 열기] 버튼으로 결과를 바로 열 수 있어요. 혹시 매칭이 잘 안 됐다면, SRT/프롬프트 대본이 서로 다르지 않은지 먼저 확인해보세요. (가장 흔한 원인)
