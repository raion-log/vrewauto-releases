🎨 FLOW 이미지 팩토리
최신 링크 자동 업데이트
대본을 분석해 이미지를 대량으로 생성해주는 도구입니다
⬅️ 자동배치 사용법으로 돌아가기
📢 꼭 읽어주세요

기존에 쓰시던 노션(Notion) FLOW 이미지생성 링크는 폐기되었습니다.
앞으로는 프로그램 안의 ‘이미지 생성’ 버튼을 눌러주세요. 이 버튼은 항상 최신 링크로 자동 연결되기 때문에, 앞으로 링크가 또 바뀌어도 버튼만 누르면 늘 최신 페이지로 들어갑니다.

🖱️ 사용방법
딱 두 단계면 됩니다
1
프로그램에서 ‘이미지 생성’ 누르기
왼쪽 메뉴에서 YouTube PD로 들어간 뒤, 맨 위 ‘이미지 생성’ 카드를 클릭하세요.
메뉴 › YouTube PD › 이미지 생성
▲ 왼쪽 ‘YouTube PD’ → 맨 위 ‘이미지 생성’ 카드를 누르세요
2
크롬에서 FLOW 이미지 팩토리 열기
버튼을 누르면 크롬에 FLOW 이미지 팩토리 페이지가 열립니다. [프로젝트에서 사용해 보기]를 누르면 바로 이미지 생성을 시작할 수 있어요.
▲ ‘프로젝트에서 사용해 보기’를 눌러 시작하세요
혹시 예전 페이지가 열린다면 · 프로그램을 완전히 껐다가 다시 켜주세요. 다시 누르면 최신 링크로 연결됩니다.
